Require: node >=v12.0.0

```bash
$ git clone https://gitlab.forge.gouv.qc.ca/igo2/igo2-api.git
$ cd igo2-api

# Install dépendencies
$ npm install

# Check files and launch dev instance
$ npm start
# Open your browser at http://localhost:5020/

# Build prod
$ npm run build.prod
$ npm run serve.prod
# Open your browser at http://localhost:5020/

```
